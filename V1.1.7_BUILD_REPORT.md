## Changes Made

### 1. **postbuild-electron.cjs** — CJS Package Configuration
The build script now writes `build/electron/package.json` with `{"type": "commonjs"}` to explicitly declare CommonJS module context. This prevents Node.js from attempting to load the Electron main/preload processes as ESM modules, which would trigger `ERR_REQUIRE_ESM`.

```javascript
try {
  fs.writeFileSync(

    JSON.stringify({ type: 'commonjs' }, null, 2) + '\n',
    'utf8'
  );
  console.log(`Wrote ${localPkgPath} with type=commonjs`);
} catch (e) {
  console.error(`Failed to write ${localPkgPath}:`, e);
  process.exitCode = 1;
}
```

## Technical Details

**Root Cause:** When webpack/esbuild/Vite transpiles TypeScript Electron main/preload to CJS format (`.js` → `.cjs`), Node.js must know to interpret them as CommonJS, not ESM. The parent `package.json` declares `"type": "module"`, so without an explicit package.json marker in `build/electron/`, Node.js would try to parse `.cjs` files as ESM, causing `ERR_REQUIRE_ESM`.

**Solution:** An explicit `build/electron/package.json` with `{"type": "commonjs"}` tells Node.js: "In this directory, files are CommonJS." This overrides the parent's ESM context for this subtree.
