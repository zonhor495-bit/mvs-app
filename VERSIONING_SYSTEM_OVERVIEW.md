## 🔄 Структура данных версии

```typescript
// В src/website/versions.ts

export interface ReleaseEntry {
  version: string;        // "1.1.8"
  date: string;          // "14 августа 2026"
  title: string;         // Название релиза
  features: string[];    // Новые функции
  fixes: string[];       // Исправления
}

// Массив в обратном хронологическом порядке (новые первыми)
export const versionHistory: ReleaseEntry[] = [
  {
    version: '1.1.8',
    date: '14 августа 2026',
    title: 'Обновление версии и подготовка системы',
    features: [
      'Система управления услугами',
      'First Run Wizard',
      'TOP-10 популярных услуг',
      'Улучшения производительности',
    ],
    fixes: [
      'Оптимизация работы приложения',
      'Исправления ошибок в сохранении данных',
      'Улучшена стабильность при работе с большим объёмом данных',
    ],
  },
  // ... старые версии идут ниже
];

// Размер для каждой версии (в МБ)
export const fileSizes: Record<string, number> = {
  '1.1.8': 84,
  '1.1.0': 84,
  '1.0.3': 82,
  // ...
};
```

## 🛠️ Процесс добавления новой версии

### Шаг 1: Обновить `package.json`

```json
{
  "version": "1.1.9"
}
```

### Шаг 2: Обновить `src/website/versions.ts`

Добавить **в начало массива**:

```typescript
export const versionHistory: ReleaseEntry[] = [
  {
    version: '1.1.9',
    date: '20 августа 2026',
    title: 'Новые возможности версии',
    features: [
      'Новая функция 1',
      'Новая функция 2',
      'Новая функция 3',
    ],
    fixes: [
      'Исправление 1',
      'Исправление 2',
    ],
  },
  // ... остальные версии
];
```

### Шаг 3: Обновить `fileSizes`

```typescript
export const fileSizes: Record<string, number> = {
  '1.1.9': 85,  // ← Новая версия
  '1.1.8': 84,
  // ...
};
```

### Шаг 4: Пересобрать

```bash
npm run build        # Веб-приложение
npm run build:win    # Windows установщик
```
