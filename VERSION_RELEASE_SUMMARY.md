## 🚀 Как добавить версию 1.1.9

### Вариант 1: Быстрый путь (для опытных)

```bash
# 1. Обновить версию в package.json
sed -i '' 's/"version": "1.1.8"/"version": "1.1.9"/' package.json

# 2. Добавить в src/website/versions.ts (в начало массива):
# {
#   version: '1.1.9',
#   date: '20 августа 2026',
#   title: 'Название версии',
#   features: ['Функция 1', 'Функция 2'],
#   fixes: ['Исправление 1'],
# }

# 3. Обновить fileSizes
# '1.1.9': 85,

# 4. Пересобрать
npm run build && npm run build:win
```

### Вариант 2: Подробный путь (для новичков)

1. Прочитать `VERSION_MANAGEMENT_GUIDE.md`
2. Следовать инструкциям пошагово
3. Использовать примеры из документа
4. Проверить чек-лист перед релизом

- Переходит на сайт → `/download`
- Видит красивую карточку версии

- Обновляет версию в `package.json`
