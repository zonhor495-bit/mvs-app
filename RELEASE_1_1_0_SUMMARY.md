## 📋 Краткое описание

Выпущена версия 1.1.0 с полной поддержкой управления услугами, автоматической популярностью и первоначальной настройкой.

## 🎯 Что внесено в 1.1.0

### Основные функции
1. **Система управления услугами**
   - Библиотека 70+ предустановленных услуг
   - Добавление, редактирование, удаление услуг
   - Статистика использования и выручки

2. **Первоначальная настройка (First-run wizard)**
   - Выбор режима: шаблон или ручное создание
   - Поиск и фильтрация услуг
   - Установка цен для всех автотипов

3. **Управление заказами**
   - TOP-10 популярные услуги
   - Мгновенный поиск и фильтрация
   - Мультиселект услуг
   - Автоматический подсчет популярности

4. **Миграция данных**
   - Полное сохранение при обновлении
   - Все старые данные остаются на месте

   ```bash

   ```

2. **На тестовой машине (Windows)**
   - Установить версию 1.0.3
   - Добавить тестовые данные
   - Запустить приложение
   - Должно обнаружить обновление на 1.1.0
   - Нажать "Обновить"
   - Проверить что данные сохранились

## 📝 Заметки для техподдержки

### Часто задаваемые вопросы
**Q: Где находятся данные пользователя?**  
A: `%APPDATA%\MVS\` на Windows

**Q: Как откатиться на старую версию?**  
A: Установить старую версию поверх текущей, данные сохранятся

**Q: Почему обновление не обнаружено?**  
A: Проверить наличие latest.yml на сервере, перезапустить приложение

**Q: Как проверить логи обновлений?**  
A: `%APPDATA%\MVS\startup.log`
