# Тестирование автообновления MVS 1.1.0

## Пошаговое руководство

### Шаг 1: Подготовка окружения

Убедитесь, что у вас есть:
- Windows 10/11 x64 (физическая машина или виртуальная)
- Интернет доступ или локальная сеть
- Node.js (для запуска локального сервера)

### Шаг 2: Запуск локального сервера обновлений

На машине для разработки запустите сервер обновлений:

```bash
cd /Users/maksim/Desktop/carwin0.4.7
node scripts/update-server.cjs
```

Ожидаемый результат:
```
🚀 Запуск локального сервера обновлений...
📁 Директория релизов: /Users/maksim/Desktop/carwin0.4.7/WD125
🌐 Сервер будет доступен на: http://localhost:3000

✅ Сервер запущен на http://localhost:3000
```

Сервер будет доступен по адресу: **http://localhost:3000**

### Шаг 3: Получение IP адреса машины разработки

Узнайте IP адрес вашей машины (для доступа из другой сети):

```bash
# macOS/Linux
ifconfig | grep "inet " | grep -v 127.0.0.1

# Windows
ipconfig | findstr IPv4
```

Запомните адрес, например: `192.168.1.100`

### Шаг 4: Подготовка версии 1.0.3

На тестовой машине (Windows):

1. **Загрузите установщик версии 1.0.3**
   - Используйте существующий установщик MVSSetup-1.0.3.exe
   - Или используйте версию из архива

2. **Установите приложение**
   - Запустите установщик
   - Завершите процесс установки
   - Не запускайте приложение после установки

3. **Добавьте тестовые данные**
   - Запустите MVS
   - Создайте новую организацию (если требуется)
   - Добавьте несколько сотрудников
   - Добавьте несколько услуг (опционально)
   - Создайте несколько заказов
   - Закройте приложение

4. **Проверьте что данные сохранились**
   - Запустите приложение снова
   - Убедитесь что все данные на месте

### Шаг 5: Настройка URL для обновлений (для локального тестирования)

**ВАЖНО**: Этот шаг требуется только для локального тестирования!

Для тестирования с локальным сервером нужно временно изменить URL:

```bash
# На машине разработки:
cd /Users/maksim/Desktop/carwin0.4.7

# Отредактируйте package.json
# Найдите строку с "url": и измените на локальный адрес

# Примерно:
# "publish": [
#   {
#     "provider": "generic",
#     "url": "http://192.168.1.100:3000"  # ИЗМЕНИТЕ НА ВАШЕ ЗНАЧЕНИЕ
#   }
# ]
```

Или используйте sed:

```bash
sed -i '' 's|"url": "[^"]*"|"url": "http://192.168.1.100:3000"|g' package.json
```

### Шаг 6: Сборка версии 1.1.0 с новым URL

```bash
# На машине разработки
cd /Users/maksim/Desktop/carwin0.4.7

# Пересоберите приложение
npm run build:win
```

Ожидаемый результат:
- Успешная компиляция
- Создан новый установщик `MVSSetup.exe`

### Шаг 7: Тестирование обнаружения обновления

На тестовой машине:

1. **Запустите приложение версии 1.0.3**
   - Если приложение уже запущено, перезапустите его

2. **Проверьте логи обновлений**
   - Откройте: `%APPDATA%\MVS\startup.log`
   - Ищите строки типа:
     ```
     [updater-info] Checking for updates
     [updater-info] Update available: 1.1.0
     ```
   - Или:
     ```
     [updater] Update available: { version: '1.1.0', ... }
     ```

3. **Должно появиться окно обновления**
   - "Доступно обновление до версии 1.1.0"
   - Две кнопки: "Обновить" и "Позже" (или "Не сейчас")

4. **Если окно не появилось**
   - Проверьте логи (может быть ошибка сети)
   - Проверьте что сервер запущен и доступен
   - Проверьте что latest.yml правильно сформирован

### Шаг 8: Выполнение обновления

На тестовой машине:

1. **Нажмите кнопку "Обновить"**
   - Начнётся загрузка нового установщика
   - В логах должны появиться строки типа:
     ```
     [updater] Download progress: 10%
     [updater] Download progress: 50%
     [updater] Download progress: 100%
     ```

2. **Дождитесь завершения загрузки**
   - Может занять несколько минут в зависимости от скорости сети
   - Приложение может показывать индикатор прогресса

3. **Приложение автоматически перезагрузится**
   - После установки обновления приложение закроется и запустится снова
   - Вы должны вернуться в главное окно приложения

4. **Проверьте версию**
   - Откройте логи: `%APPDATA%\MVS\startup.log`
   - В новой записи должно быть: `App Version: 1.1.0`
   - Или проверьте в окне приложения (если там отображается версия)

### Шаг 9: Проверка сохранения данных

После успешного обновления:

1. **Все данные должны остаться на месте**
   - ✅ Организация
   - ✅ Сотрудники
   - ✅ Услуги (если были добавлены)
   - ✅ Цены
   - ✅ Клиенты
   - ✅ Заказы
   - ✅ История заказов
   - ✅ Настройки
   - ✅ Роли и пароли

2. **Проверьте новые функции версии 1.1.0**
   - Откройте "Настройки" → "Услуги"
   - Должен быть список услуг с возможностью редактирования
   - При создании заказа должны видны TOP-10 услуг

### Шаг 10: Возврат на исходный URL (для разработки)

После тестирования верните исходный URL:

```bash
# На машине разработки
cd /Users/maksim/Desktop/carwin0.4.7

# Верните GitHub URL
sed -i '' 's|"url": "[^"]*"|"url": "https://github.com/maksim-desktop/mvs-app/releases/download/latest"|g' package.json

# Или отредактируйте вручную в package.json
```

## Возможные проблемы и решения

### Обновление не обнаружено

**Проблема**: Окно обновления не появляется

**Решение**:
1. Проверьте что сервер запущен: `node scripts/update-server.cjs`
2. Проверьте что firewall разрешает доступ
3. Проверьте что latest.yml доступен по адресу `http://IP:3000/latest.yml`
4. Проверьте логи: `%APPDATA%\MVS\startup.log`
5. Перезапустите приложение

### Загрузка зависает

**Проблема**: Обновление загружается бесконечно

**Решение**:
1. Проверьте скорость сети
2. Проверьте что установщик полностью скопирован в WD125
3. Проверьте размер файла в latest.yml vs реальный размер
4. Закройте и перезапустите приложение

### Данные не сохранились

**Проблема**: После обновления исчезли данные

**Решение**:
1. Это не должно происходить при правильном обновлении
2. Проверьте что папка `%APPDATA%\MVS\` не была удалена
3. Попробуйте откатиться на версию 1.0.3 (данные должны восстановиться)
4. Обратитесь в поддержку

### Версия не изменилась

**Проблема**: После обновления версия всё ещё 1.0.3

**Решение**:
1. Проверьте что версия в package.json действительно 1.1.0
2. Проверьте что новый установщик был собран правильно
3. Проверьте логи: может быть обновление не завершилось
4. Попробуйте очистить кэш electron-updater: `%APPDATA%\electron-updater\`

## Откат на предыдущую версию

Если обновление прошло неправильно:

1. **Закройте приложение**
2. **Удалите файлы обновления**
   - `%APPDATA%\electron-updater\`
3. **Установите версию 1.0.3 поверх текущей**
   - Данные не будут удалены
4. **Проверьте что данные восстановились**
