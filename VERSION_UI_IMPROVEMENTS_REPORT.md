### 1. ✅ Централизованная система управления версиями

Создан новый файл `src/website/versions.ts` — центральное хранилище всех версий и их метаданных.

**Преимущества:**
- Одно место для обновления информации о версии
- Легко добавлять новые версии без редактирования компонентов React
- Масштабируемо: система готова к версиям 1.1.9, 1.2.0 и далее
- Система не требует изменения кода при добавлении новой версии

**Файл: `src/website/versions.ts`**
```typescript
// Структура версии:
export interface ReleaseEntry {
  version: string;           // "1.1.8"
  date: string;             // "14 августа 2026"
  title: string;            // "Обновление версии..."
  features: string[];       // Новые функции
  fixes: string[];          // Исправления
}

// История релизов в обратном хронологическом порядке (новые первыми)
export const versionHistory: ReleaseEntry[] = [
  { version: '1.1.8', ... },
  { version: '1.1.0', ... },
  { version: '1.0.3', ... },
  // и так далее...
]

// Размер файла для каждой версии (в МБ)
export const fileSizes: Record<string, number> = {
  '1.1.8': 84,
  '1.1.0': 84,
  '1.0.3': 82,
  // ...
}
```

### 5. ✅ Система готова к будущим версиям

**Для добавления версии 1.1.9:**

1. Обновить версию в `package.json`:
```json
{
  "version": "1.1.9"
}
```

2. Добавить запись в `src/website/versions.ts` (в начало массива):
```typescript
{
  version: '1.1.9',
  date: '20 августа 2026',
  title: 'Новая версия с улучшениями',
  features: [
    'Новая функция 1',
    'Новая функция 2',
  ],
  fixes: [
    'Исправление 1',
    'Исправление 2',
  ],
}
```

3. Добавить размер в `fileSizes`:
```typescript
fileSizes['1.1.9'] = 85;
```

4. Пересобрать:
```bash
npm run build
npm run build:win
```

**Всё!** Система автоматически обновит:
- Страницу загрузки (версия, дата, размер, фичи)
- Страницу changelog (добавит новую версию в начало)
- dist/index.html (новая версия в HEAD)
- Electron приложение (version в About)

## 💻 Технические детали

### Архитектура версионирования

```
package.json (версия 1.1.8)
       ↓
vite.config.ts (читает версию)
       ↓
__APP_VERSION__ = "1.1.8" (глобальная переменная)
       ↓
vite-env.d.ts (тип declaration)
       ↓
src/website/versions.ts (определяет VersionHistory)
       ↓
src/website/WebsiteApp.tsx (использует versions.ts)
       ↓
dist/index.html (встроенная версия в JS)
       ↓
Браузер пользователя (отображает 1.1.8)
```

```typescript
// Новый подход: центральное управление
```
