## 🆘 Решение проблем при развертывании

### Проблема: "Модальное окно не открывается"
```
Решение:
1. Очистить кэш браузера (Ctrl+Shift+Del)
2. Перезагрузить страницу (F5)
3. Проверить консоль браузера (F12) на ошибки
```

### Проблема: "Пароль не работает"
```
Решение:
1. Проверить правильность ввода
2. Убедиться что нет случайных пробелов
3. Посмотреть Caps Lock
4. Сбросить пароли в localStorage
```

### Проблема: "Ограничение не работает"
```
Решение:
1. Проверить что роль действительно изменилась
2. Перезагрузить страницу
3. Очистить localStorage: 
   localStorage.removeItem('wd_role_passwords')
4. Проверить консоль на JavaScript ошибки
```

### Проблема: "Система медленно загружается"
```
Решение:
1. Проверить скорость интернета
2. Посмотреть Network tab в DevTools (F12)
3. Убедиться что все JS файлы загружены
4. Проверить размер бандла (3.2 MB нормально)
```
