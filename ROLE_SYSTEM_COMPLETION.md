## 🎯 Использование системы

### Переключение роли:
```
1. Нажать на текущую роль в нижней части боковой панели
2. Выбрать целевую роль из меню
3. Ввести пароль в модальном окне
4. Нажать "Подтвердить"
5. Роль автоматически переключится
```

### Изменение пароля:
```
1. Открыть "Настройки" (⚙️)
2. Перейти на вкладку "Система"
3. Ввести новые пароли
4. Нажать "Сохранить пароли"
5. Увидеть подтверждение сохранения
```
