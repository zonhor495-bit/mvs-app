## 🔧 Файлы с кодом (измененные)

### Основные компоненты

#### 1. **src/store.ts**
- **Функции добавлены**:
  - `getRolePasswords()` - получить пароли ролей
  - `setRolePassword(role, password)` - установить пароль
  - `verifyRolePassword(role, password)` - проверить пароль
- **Константы добавлены**:
  - `DEFAULT_ROLE_PASSWORDS` - пароли по умолчанию
- **Типы добавлены**:
  - `RolePasswords` - тип для паролей
- **Локалхранилище**: `wd_role_passwords`

#### 2. **src/components/Layout.tsx**
- **Пропсы добавлены**:
  - `onRoleChange: (role: UserRole) => void`
- **State добавлены**:
  - `isRoleMenuOpen` - открыто ли меню ролей
  - `rolePromptOpen` - открыто ли модальное окно
  - `pendingRole` - целевая роль
  - `rolePassword` - введенный пароль
  - `roleError` - сообщение об ошибке
- **Методы добавлены**:
  - `handleRoleSelect(role)` - открыть подтверждение
  - `confirmRoleSwitch()` - проверить пароль
- **UI добавлено**:
  - Меню ролей в боковой панели
  - Модальное окно с паролем

#### 3. **src/app/InternalApp.tsx**
- **Импорты добавлены**:
  - `UserRole` из types
- **Методы добавлены**:
  - `handleRoleChange(role)` - переключить роль
- **Логика добавлена**:
  - Проверка доступа в `renderPage()`
  - Сообщение об ограничении
  - Передача callback в Layout
- **Ограничение**:
  - Admin не может: washers, settings

#### 4. **src/components/Settings.tsx**
- **Импорты добавлены**:
  - `getRolePasswords`, `setRolePassword`
- **State добавлены**:
  - `managerRolePassword` - пароль управляющего
  - `adminRolePassword` - пароль администратора
  - `passwordSaveMessage` - сообщение сохранения
- **Методы добавлены**:
  - `handleSaveRolePasswords()` - сохранить пароли
- **UI добавлено**:
  - Форма в вкладке "Система"
  - Два поля ввода паролей
  - Кнопка сохранить

#### 5. **src/index.css** (не менялось)
- **CSS классы уже существуют**:
  - `.modal-overlay` - фон модали
  - `.modal-panel` - панель модали
  - Используются как есть

#### 6. **src/types.ts** (не менялось)
- **UserRole тип уже существует**: `'admin' | 'manager'`
- Используется без изменений
